# 🤖 NeuroCopy - AI Sales Assistant Builder

## 🧠 Описание
**NeuroCopy** - революционная система для создания персонализированных AI-ассистентов продаж на основе анализа реальных диалогов. Система изучает стиль общения, аргументацию и техники продаж из собранных сообщений Telegram, создавая цифровой клон, который может вести эффективные продающие диалоги в вашем стиле.

## 🚀 Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/wsgp2/---NeuroCopy---AI-Sales-Assistant-Builder--SergD-.git
cd ---NeuroCopy---AI-Sales-Assistant-Builder--SergD-
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Создайте файл `.env` со следующими параметрами:
```
# Telegram API (для сбора сообщений)
API_ID=your_api_id
API_HASH=your_api_hash
PHONE=your_phone_number

# OpenAI API (для генерации ответов)
OPENAI_API_KEY=your_openai_api_key

# Telegram Bot API (для интерфейса бота)
TELEGRAM_BOT_TOKEN=your_bot_token
```

### 4. Получение API-ключей
- **Telegram API**: Создайте приложение на [my.telegram.org](https://my.telegram.org/auth)
- **OpenAI API**: Получите ключ на [platform.openai.com](https://platform.openai.com/api-keys)
- **Telegram Bot**: Создайте бота через [@BotFather](https://t.me/BotFather)

## 💡 Использование

### 1. Сбор сообщений продавца
```bash
python tg_message_collector.py
```
Скрипт соберет все сообщения из личных чатов пользователя для обучения AI-ассистента. Система анализирует только сообщения владельца аккаунта, соблюдая конфиденциальность других участников чата.

### 2. Создание векторной базы данных
```bash
python vectorizer.py
```
Собранные сообщения преобразуются в векторные представления и сохраняются в ChromaDB для эффективного семантического поиска.

### 3. Тестирование генерации ответов
```bash
# Интерактивный режим
python response_generator.py --interactive

# Одиночный запрос
python response_generator.py --query "Какие у вас есть тарифы и цены?"
```

### 4. Запуск Telegram-бота
```bash
python telegram_bot.py
```
Запускает полноценного бота в Telegram, который отвечает клиентам в стиле продавца-донора.

## 🧠 Как работает система

1. **Сбор данных**
   - Анализ всех личных чатов продавца-донора
   - Сбор всех сообщений без ограничений по количеству
   - Классификация контекстов и ситуаций продаж

2. **Векторизация**
   - Преобразование сообщений в векторные представления
   - Индексация для быстрого семантического поиска
   - Оптимизированная обработка дубликатов

3. **Генерация ответов**
   - Поиск семантически близких примеров ответов в базе
   - Формирование контекста с историческими данными
   - Генерация новых ответов с сохранением стиля продавца
   - Постобработка для поддержания целостности диалога

4. **Память диалога**
   - Сохранение контекста до 1000 сообщений в диалоге
   - Поддержка длительных продающих разговоров
   - Умная фильтрация релевантной информации

## 🔐 Конфиденциальность и безопасность

- **Локальное хранение**: Все данные хранятся только на вашем устройстве
- **Обучение на ваших данных**: Система анализирует только сообщения продавца
- **Контроль доступа**: API-ключи хранятся в безопасном файле .env
- **Селективная память**: Возможность фильтрации и исключения конфиденциальной информации

## 📊 Примеры использования

### Обучение на диалогах лучшего продавца
1. Получите доступ к сообщениям вашего лучшего менеджера по продажам
2. Соберите его диалоги с клиентами с помощью `tg_message_collector.py`
3. Создайте векторную базу знаний с `vectorizer.py`
4. Запустите Telegram-бота, который будет отвечать новым клиентам в стиле этого продавца

### Создание специализированных ассистентов
- **Ассистент по техническим вопросам**: обучение на диалогах технических специалистов
- **Ассистент онбординга**: обучение на диалогах с новыми клиентами
- **Специалист по удержанию**: обучение на успешных случаях удержания клиентов

## 🧩 Архитектура системы

- **telegram_bot.py**: интерфейс Telegram-бота для взаимодействия с клиентами
